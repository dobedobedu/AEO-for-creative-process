# Trigger Library (MVP)

## Stage: Explore (awareness / life events)
- Relocation for new job
- Growing family (new child / more space)
- Retirement / downsizing
- Remote work relocation
- Empty nest (kids moved out)
- First-time homebuyer
- Investment / second-home interest

## Stage: Consider (shortlist / evaluation)
- Builder reputation & build quality
- Community amenities & lifestyle fit
- Schools & district reputation
- Safety / crime rate
- HOA fees / community rules
- Commute & access to services
- Property taxes / insurance
- Resale value potential

## Stage: Compare (alternatives)
- Lakewood Ranch vs another community
- Lakewood Ranch vs Sarasota / Bradenton
- Builder A vs Builder B
- New build vs resale in same area
- Price per sq ft comparisons
- Amenities comparison

## Notes
- Keep to 3 stages for MVP.
- Allow custom triggers per stage.
- Add "Context Enrichment" later to suggest seasonal or macroeconomic triggers.
